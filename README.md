# Resolve Fortune Cookies

A ready-to-upload static website with 60 fortunes, the Resolve wordmark, and the pink/plum design.

## Publish on GitHub Pages

1. Sign in at https://github.com/new and create a public repository named resolve-fortune-cookie. Turn on Add README.
2. Unzip this download on your computer.
3. Open the repository, choose Add file > Upload files, and drag in all the extracted files and the assets folder. Upload the contents, not the ZIP or its enclosing folder. index.html must appear at the repository's top level. Replace the starter README if prompted.
4. Commit the files to main.
5. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch. Select main and /(root), then Save.
6. When publishing finishes, use the Visit site link shown in Settings > Pages. It normally looks like https://YOUR-USERNAME.github.io/resolve-fortune-cookie/.

GitHub Pages can take up to 10 minutes to publish. Visitors open the public website without a GitHub account.

## Edit later

- Fortune wording: app.js
- Layout: index.html
- Colors and spacing: style.css
- Images and font: assets/

No installation or build step is needed. All fonts and images are included. The site uses no external APIs, analytics, or saved visitor data.
